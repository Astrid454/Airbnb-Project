# Airbnb Web Platform (PHP + MySQL)

A marketplace-style web application inspired by Airbnb, where users can register as **Host** or **Guest**, manage listings, and handle reservations. The project focuses on core full-stack web fundamentals: authentication, database design, and CRUD operations.

## Features

### Authentication & Roles
- User registration and login
- Role-based accounts: **Host** / **Guest**
- Password hashing for secure credential storage
- Email uniqueness validation during signup

### Host
- Create, update, and delete listings
- Manage own listings from a dedicated dashboard

### Guest
- Browse available listings
- Make reservations
- Guest dashboard for managing activity

## Tech Stack
- **Frontend:** HTML, CSS  
- **Backend:** PHP  
- **Database:** MySQL (SQL)

### Prerequisites
- XAMPP / WAMP / MAMP (or any PHP + MySQL environment)
- PHP 7+ 
- MySQL
